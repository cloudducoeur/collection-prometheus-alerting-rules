# Contributing

We welcome contributions to the Prometheus Alerting Rules Collection!

![](./cdc-contribute.png)

## Repository

You can find the source code and contribute on our GitHub repository:
[https://github.com/cloudducoeur/collection-prometheus-alerting-rules](https://github.com/cloudducoeur/collection-prometheus-alerting-rules)

## How to contribute

1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Add your changes.
4. Submit a pull request.
